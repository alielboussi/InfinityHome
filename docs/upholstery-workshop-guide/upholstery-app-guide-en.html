Internal upholstery workshop guide — Infinity Home

2) What each page is for

Create new item

Add a seating product that is not in the catalog yet. It is saved on the /upholstery web portal with the quantity you type, plus an AI-retouched catalog photo.

  1. Enter the base name, then pick the seating type (3 seater, recliner, and so on).
  2. Enter dimensions in cm and quantity (must be 1 or more).
  3. Photograph the piece when asked. Wait for the AI photo, then Save.
  4. The same qty is injected on the portal with the photo — not 0.

Manufacture

Grid of Floor 2 raw WIP only. Tapping deducts that qty from Floor 2 and opens a production job on Orders.

  1. Search or scan the Floor 2 label barcode / QR.
  2. Tap the card → enter quantity (cannot exceed Floor 2 on hand).
  3. Confirm. Floor 2 raw is deducted now. Open Orders to add materials and finish.

Orders — factory quotes (QT#)

Customer / showroom orders sent to upholstery. Quote number is top-right. Badges: Customer order or Showroom order. Orders can start even if Floor 2 qty is 0 — manufacture first if stock is short.

  1. Play ▶ accept the order and start the timer.
  2. Pause ⏸ stop the timer without finishing.
  3. Completed items stepper (− / number / + then ✓): how many pieces of that line are ready.
  4. Then choose Floor 1 stock or Send to delivery. You can send a partial qty (for example 3 of 8) before the whole order is complete. Completed qty can only go up.
  5. Stop ⏹ end the whole order when every line is done.
  6. Wrench storeroom materials used on the order.

Orders — manufacture jobs

Jobs opened from Manufacture. Timer runs while you work. Use the same completed-qty stepper for pieces on the job.

  1. ▶ Play / ⏸ Pause the timer.
  2. Wrench: add storeroom materials (scan or search) and pick storeroom 1 / 2 / 3.
  3. ⏹ Finish: choose Floor 1 (finished warehouse stock + Zebra labels) or Delivery (virtual hold in the Delivery app).

Orders — repairs

Customer returns for upholstery appear in the same Orders list (Repair badge).

  1. ▶ Accept the repair and start work.
  2. ⏸ Pause.
  3. Wrench to add materials if needed.
  4. ⏹ Complete — the repair joins the Delivery app Repairs queue (awaiting driver). Warehouse floors are not credited.

Search on Orders

Search by quote number QT, customer name, or phone. The list mixes quotes, jobs, and repairs.
