OUTSIDE THE REPO — WHERE YOU MUST UPDATE THE DOMAIN
================================================================================

1) VERCEL (vercel.com → your project)
   - Domains: wait until infinity-home.online shows "Valid Configuration"
   - Environment variables (Production):
       REACT_APP_CANONICAL_HOST=www.infinity-home.online
       REACT_APP_CANONICAL_ORIGIN=https://www.infinity-home.online
       MTN_MOMO_CALLBACK_HOST=https://www.infinity-home.online
   - Redeploy after env changes

2) FIREBASE CONSOLE (console.firebase.google.com)
   - Authentication → Settings → Authorized domains
   - ADD: infinity-home.online
   - ADD: www.infinity-home.online
   - Do NOT change authDomain (stays *.firebaseapp.com)

3) GOOGLE CLOUD CONSOLE (only if staff use Google sign-in)
   - APIs & Services → Credentials → OAuth 2.0 Client IDs
   - Authorized JavaScript origins:
       https://www.infinity-home.online
       https://infinity-home.online
   - Authorized redirect URIs (if listed):
       https://www.infinity-home.online/__/auth/handler
       (match whatever Firebase shows for your Web client)

4) MTN MOMO — momodeveloper.mtn.com
   - Recreate or update API User providerCallbackHost to:
       www.infinity-home.online
     (hostname only — no https://)
   - If you cannot edit existing user, create a new sandbox API user with the new host

5) MTN MOMO — developers.mtn.com (if you registered Payments V1 app there)
   - App → Callback URL:
       https://www.infinity-home.online/api/web-orders?action=payment-callback&provider=mtn

6) WASENDERAPI (wasenderapi.com)
   - No domain change required (API token only)
   - Renew subscription if "past due" errors appear on POS WhatsApp alerts

7) LABEL WORKER PC (if you run label-worker/worker.py locally)
   - label-worker/.env:
       INFINITY_API_BASE=https://www.infinity-home.online

8) EXPO MOBILE APPS (each app folder .env)
   - EXPO_PUBLIC_API_BASE=https://www.infinity-home.online
   - EXPO_PUBLIC_APP_URL=https://www.infinity-home.online/layby-management (layby-shell)
   - Rebuild/republish apps after changing

9) DOMAIN REGISTRAR (where you bought infinity-home.online)
   - If bought on Vercel: nameservers usually auto-configured
   - If bought elsewhere: point nameservers to Vercel per "View DNS configuration"

10) MARKETING & OPERATIONS (manual)
    - Google / Meta / social ads → landing URL /shop
    - WhatsApp business bio / link in chat
    - Email signatures, invoices, printed QR codes
    - Bookmarks on staff phones/tablets
    - Google Search Console property (add new domain when live)

11) NOT REQUIRED TO CHANGE
    - Firebase Firestore / Storage rules (no domain in rules)
    - WasenderAPI group IDs
    - SMTP email (uses mail server host, not your app domain)
    - Firebase project ID or storage bucket names
