# Orders (Expo)

Hassan Awad quotationer dashboard as a lightweight Android app.

Dashboard tiles (fixed order): Customers, Products, New Order, Orders, Deliveries, Repairs, Storage, Tracking.

Sign-in: Google and email/password. Hassan Awad (`hassanawad18@gmail.com`) and the User Access admin always have every page. Other staff need **User Access → Orders** per page.

```bash
cd mobile-apps/orders
npm install
npm start
```
